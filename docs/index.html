What it does

Everything here exists because the alternative was four terminal tabs and a guess.

⇥Survives the app

Services run inside tmux. Quit Harbor and your dev server keeps serving; open it again and it is still there, still green, still on :3000. An update never touches them.

⌁Ports are measured

You never type a port into Harbor. It walks the tmux pane's process tree and asks lsof what is actually listening — then gives you a button that opens it.

✦Magic

Claude reads the project and proposes its services — monorepos, PM2 configs, socket servers, cron processes — with the file each one came from. Read-only, and nothing is added until you tick it.

◧The edge strip

A column of project chips floating on the right edge, above every app and on every Space. Hover to see every service; press play without losing focus in your editor.

⚠Crashes stay readable

A service that exits keeps its output and exit code instead of vanishing. If the port was taken, the row names the process holding it and offers to kill it.

⌘Quick switcher

⌃⌘H from anywhere: type a project or service name, Enter starts or stops it. No window, no mouse. The same list lives in the menu bar.

How it works

Three decisions the whole app rests on.

One tmux session per service

Named from a stable hash of the project path, so the same folder maps to the same session on every launch — which is how Harbor finds services it did not start in this run and adopts them instead of starting a second copy.

One poll answers for everything

Every two seconds: one list-panes for liveness and exit codes, one ps for the process tree, one lsof for the ports. No per-service polling, and nothing is drawn again unless the value actually changed.

A port is not an answer

Give a service a health path and the dot goes green only when the URL responds — not when the port opens. While a framework is still booting, yellow is the truth.

# a service, really
tmux -S /tmp/harbor-501.sock \
  new-session -d -s hb-3b92hjqj-5de35ab8 \
  'cd backend && npm run dev'

# what the dot means
● running   alive · answering · :4000
● starting  alive, nothing listening yet
● exited    kept, with its exit code
○ stopped

Install

Clone and run one script. It installs tmux with Homebrew if you do not have it.

git clone https://github.com/erenbekman/harbor.git
cd harbor
./install.sh
Add a folderHarbor reads it and offers what it finds — npm, pnpm, yarn or bun scripts, artisan, Django, docker compose.
Or press MagicClaude reads the project for anything the pattern matching cannot see.
It updates itselfSettings → About checks the latest release and installs it; your services keep running through it.
